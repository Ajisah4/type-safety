# Generic Constraints

<EpicVideo url="https://www.epicweb.dev/workshops/type-safety/6-generics/constraints" />

👨‍💼 Sometimes you need to limit what types can be used with a generic. For
example, a function that accesses `.length` only works with types that have a
`length` property.

```ts
// ❌ Error: Value might not have .length
function logLength<Value>(value: Value) {
	console.log(value.length)
}

// ✅ Constrain Value to types with length
function logLength<Value extends { length: number }>(value: Value) {
	console.log(value.length) // Safe!
}

logLength('hello') // ✅ strings have length
logLength([1, 2, 3]) // ✅ arrays have length
logLength(42) // ❌ Error: number has no length
```

Use `extends` to add constraints.

🐨 Open <InlineFile file="index.ts" /> and:

1. Implement `getId` — accepts objects that have `id: string` and returns that
   `id`
2. Implement `getProperty` — takes an object and a key of that object, returns
   the value at that key with the correct type
3. Implement `merge` — takes two objects and returns one object with properties
   from both; when keys overlap, the second argument wins
4. Export `getId`, `getProperty`, and `merge` by name

## Completion criteria

- Named exports: `getId`, `getProperty`, `merge`
- `getId({ id: '1', name: 'Alice' })` → `'1'`
- `getProperty(user, 'email')` returns the email string
- `merge({ a: 1, b: 2 }, { b: 3, c: 4 })` → `{ a: 1, b: 3, c: 4 }`

<callout-info>
	This is a small preview of **type operators**. We'll dive deeper into these in
	the Advanced TypeScript workshop.

    `keyof ObjectType` produces a union of all property names of type ObjectType.
    For example, if ObjectType is `{ name: string; age: number }`, then
    `keyof ObjectType` is `'name' | 'age'`.

    `ObjectType[Key]` is an **indexed access type** - it gives you the type of
    property Key on type ObjectType. If ObjectType is `{ name: string }` and Key
    is `'name'`, then `ObjectType[Key]` is `string`.

</callout-info>
